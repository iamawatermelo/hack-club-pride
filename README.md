# hack-club-pride

Stupidly simple Manifest V3 extension to change the Hack Club Slack
logo. 

## Installation

- First, review the [extension source code](scripts/pride.js) to
  determine whether you trust this extension.
- Download and unzip the source code.
- Optionally change the URL in `scripts/pride.js` if you want a
  different logo.
- Load unpacked in your browser.
